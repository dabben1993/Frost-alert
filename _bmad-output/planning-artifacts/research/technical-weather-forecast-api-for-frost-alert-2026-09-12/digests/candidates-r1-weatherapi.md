> **Candidate:** WeatherAPI.com
> **Decision served:** Selecting a weather forecast data source for a hobby frost-alert automation (primary test case: Sweden), warning before overnight lows threaten outdoor plants.
> **Researcher note:** Research-firewalled session; no project files consulted beyond this brief.

## Claims

- WeatherAPI.com's Free plan is $0/month, includes 100,000 API calls per month, a 3-day forecast, and 1 day of historical weather (no explicit separate daily-call cap is published — only the monthly cap) — source: WeatherAPI.com, "Pricing" page, https://www.weatherapi.com/pricing.aspx, published: undated (live pricing table), accessed: 2026-09-12, confidence: high, class: pricing
- The Free plan provides both daily and hourly forecast frequency (not just daily) — source: WeatherAPI.com, "Pricing" page, https://www.weatherapi.com/pricing.aspx, published: undated, accessed: 2026-09-12, confidence: high, class: pricing
- An independent developer review confirms the free tier's current limits as 100,000 calls/month, current conditions, a 3-day forecast, and 1 day of history, with commercial use permitted — source: DEV Community, "A Survey of Public APIs... Part 2: Weather API Review" by leomarsh886, https://dev.to/leomarsh886/a-survey-of-public-apis-for-building-a-football-live-score-site-in-2026-part-2-weather-api-review-4g3k, published: 2026 (exact date not shown), accessed: 2026-09-12, confidence: high, class: pricing
- The free tier's advertised uptime SLA is only 95.5%, notably lower than paid tiers (99%–100%) — source: WeatherAPI.com, "Pricing" page, https://www.weatherapi.com/pricing.aspx, accessed: 2026-09-12, confidence: high, class: reliability
- Because the Free plan's forecast horizon is capped at 3 days, hourly time-resolution data is likewise only available out to 3 days ahead on the free tier; the days parameter (1–14) is documented for the /forecast.json endpoint generally, but the free-tier plan cap (3 days) is the binding limit — source: WeatherAPI.com, API docs, https://www.weatherapi.com/docs/, accessed: 2026-09-12, confidence: high, class: coverage
- Forecast weather is model-derived (not raw observations) and is refreshed only every 4–6 hours per day, which matters for how "fresh" an overnight-low forecast is when checked at different times of day — source: WeatherAPI.com, "Pricing" FAQ, https://www.weatherapi.com/pricing.aspx, accessed: 2026-09-12, confidence: high, class: accuracy
- In a US-based (Boone, NC) multi-provider daily accuracy scoreboard over 77 days, WeatherAPI scored 85.4/100 overall — essentially tied with OpenWeather (85.5) but behind Visual Crossing (91.1), MET Norway (94.8), and Google (94.6); WeatherAPI's score also degraded faster at longer lead times (no 3–5 day-out data reported, unlike competitors) — source: Dave's Sweater, "Right Ray / Wrong Ray: Boone forecast accuracy scoreboard," https://davessweater.com/right-wrong-ray, published: ongoing/undated (rolling scoreboard), accessed: 2026-09-12, confidence: medium, class: accuracy — NOTE: single independent source, US location only, not Sweden/Europe; treat as directional, not conclusive.
- No provider in the free/low-cost tier space, including WeatherAPI, publishes an independent, large-scale, station-based accuracy benchmark; this is described as a structural gap across the whole category, not specific to WeatherAPI — source: jua.ai, "Free Weather API Comparison 2026," https://jua.ai/articles/free-weather-api-comparison-2026/, accessed: 2026-09-12, confidence: medium, class: accuracy
- A second, independent source makes the same point — there is no credible documentation-based way to declare WeatherAPI (or any provider) "most accurate"; accuracy must be measured locally against observations — source: DEV Community, "A Survey of Public APIs... Part 2," https://dev.to/leomarsh886/..., accessed: 2026-09-12, confidence: medium, class: accuracy
- I found no accuracy comparison specific to Sweden or Northern Europe for WeatherAPI.com in this session — see "Could not find."
- Location can be specified directly via city name (e.g. `q=Paris`), US zip, UK postcode, Canada postal code, metar/iata codes, IP address/`auto:ip`, lat/lon, or an ID returned from the Search API — source: WeatherAPI.com, API docs ("Request parameter" table), https://www.weatherapi.com/docs/, accessed: 2026-09-12, confidence: high, class: integration
- WeatherAPI.com provides a dedicated Search/Autocomplete API (`/search.json`) that returns matching cities/towns as location objects with lat/lon — i.e., built-in geocoding/autocomplete is available, separate from the forecast call — source: WeatherAPI.com, API docs, https://www.weatherapi.com/docs/, accessed: 2026-09-12, confidence: high, class: integration
- Response formats are JSON and XML; auth is via an API key passed as a query parameter; official SDKs are published on GitHub for popular languages/frameworks — source: WeatherAPI.com, API docs, https://www.weatherapi.com/docs/, accessed: 2026-09-12, confidence: high, class: integration
- A third-party API directory measured this API (methodology unspecified) at ~95–122 ms average latency but only ~81–83% observed success rate over its monitoring window — notably below the provider's advertised up-to-99.99% uptime for paid tiers (and well above the Free tier's own stated 95.5% SLA) — source: APIMemo, "WeatherAPI.com Review," https://apimemo.com/api/weatherapi-com, published: reviewed June 10, 2026 (per page), accessed: 2026-09-12, confidence: low, class: reliability — NOTE: single source, third-party directory metric, methodology not disclosed; treat as a flag to verify with your own monitoring, not a settled fact.
- The current Free plan requires no credit card at signup (new accounts get a free 7-day Business-tier trial that auto-downgrades to Free afterward) — source: WeatherAPI.com, "Signup" page, https://www.weatherapi.com/signup.aspx/, accessed: 2026-09-12, confidence: high, class: pricing
- WeatherAPI.com's own changelog states the platform launched with "a free tier with no credit card required" — source: WeatherAPI.com, "API Changelog," https://www.weatherapi.com/api-changelog.html, published: undated (changelog entry), accessed: 2026-09-12, confidence: medium, class: pricing
- Historical community reports show the free tier's terms have changed over time and caused user confusion: a Node-RED forum post from 2022 described the free tier as offering 1,000,000 calls/month (10x today's 100K) and users questioning ambiguous "renewal" language in signup emails; separately, a 2022 GitHub issue on an unrelated project claimed WeatherAPI had "dropped" its free plan entirely, though a 2024 comment on the same thread confirms a free plan exists again — source: Node-RED Forum, "WeatherAPI.com weather service," https://discourse.nodered.org/t/weatherapi-com-weather-service/64216, published: 2022 (thread), accessed: 2026-09-12, confidence: medium, class: reliability
- Corroborating the above, a GitHub issue thread ("weatherapi dropped free plan," monicahq/monica #6288) shows a user reporting no free plan in Aug 2022 and another user confirming in Jun 2024 that a free plan is available again, indicating policy churn rather than a permanent removal — source: GitHub, monicahq/monica issue #6288, https://github.com/monicahq/monica/issues/6288, published: 2022-08-27 (opened), updated 2024-06-29, accessed: 2026-09-12, confidence: medium, class: reliability

## Leads

- WeatherAPI.com's own blog post ("Top 5 Weather APIs for Developers in 2026") claims "14-day forecasts" and "Excellent" documentation for WeatherAPI.com generally — this conflicts with the pricing page's explicit "3 Day" forecast limit for the Free plan specifically. This is first-party marketing copy comparing itself favorably to competitors; treat it as promotional and prefer the pricing page's plan-specific table. Worth flagging in the final comparison doc as a "marketing vs. actual free-tier limit" discrepancy.
- The free tier's historical call-limit change (1M calls/month reported in 2022 vs. 100K today) suggests WeatherAPI.com has tightened its free tier over time. Worth a follow-up check via the Wayback Machine on weatherapi.com/pricing.aspx to establish a timeline of exactly when/how the free tier shrank, in case it signals a trend that could continue.
- No Sweden-specific or Nordic accuracy data was found. A useful next step (out of scope for this brief's budget) would be to run WeatherAPI.com's `/forecast.json` for a Swedish coordinate for a few weeks against SMHI (Sweden's national meteorological service) or MET Norway observations, since MET Norway scored notably higher than WeatherAPI in the one comparison found (94.8 vs 85.4).
- The APIMemo "81% success rate" figure deserves independent verification — it's a single third-party data point with no stated sample size, testing frequency, or endpoint mix.
- Not checked in this session: WeatherAPI.com's specific alert/webhook capabilities for proactive frost warnings (the pricing table shows "Weather Alerts: Limited" on Free plan but the docs weren't searched for what "limited" means exactly).
